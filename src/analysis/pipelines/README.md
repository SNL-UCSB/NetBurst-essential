# Analysis Pipeline Configs (`src/analysis/pipelines`)

## What this module does

Provides JSON defaults for `src/analysis/run_analysis_pipeline.py`.

## How to use

- Start from a defaults JSON.
- Create your run JSON with real input/output paths.
- Run with the matching subcommand.

Defaults:

- `global_cka_only.defaults.json`
- `anisotropy_only.defaults.json`
- `cluster_features.defaults.json`
- `normalized_cka_cohen.defaults.json`
